# Zoyacdeck

Windows 用の小さなボタンパネルです。画面の好きな場所に置ける、ソフトウェア版のストリームデッキです。
プログラムやサイトを開く、音楽を操作する、マイクをミュートする、音声デバイスを切り替える、画面を録画する — どれもワンクリックでできます。

English · 한국어 · 日本語

## ダウンロード

**[最新リリース](https://github.com/koishilab514/zoyacdeck/releases/latest)** から `Zoyacdeck-バージョン.zip` をダウンロードして展開し、`Zoyacdeck.exe` を実行してください。インストールは不要です。

- Windows 10 / 11（64ビット）
- 初回起動時に「Windows によって PC が保護されました」と表示された場合は、**詳細情報 → 実行** を押してください。署名していない個人制作のソフトのため表示されます。

## できること

- **開く**：プログラム・フォルダー・インストール済みアプリ・Web サイト。デスクトップのショートカットやブラウザーのアドレスを空きマスにドラッグしても追加できます。
- **音楽**：前の曲・再生/一時停止・次の曲、曲名と音量が表示されるメディアバー
- **サウンド**：出力デバイスとプログラムごとの音量を変えるパネル、ワンクリックでのデバイス切り替え、特定のプログラムだけミュート、マイクのミュート
- **録画**：モニター全体・範囲・ウィンドウを録画。そのプログラムの音だけを録ることもできます。GPU でエンコードするので、ゲームが重くなりにくいです。
- **キャプチャ**：範囲・ウィンドウのスクリーンショットを PNG で保存し、クリップボードにもコピー
- **ウィジェット**：時計、日付、CPU / GPU / RAM の使用率、タイマー・ストップウォッチ、PC の自動シャットダウン予約
- **カスタマイズ**：5種類のカラーテーマ、ボタンに好きな画像や動く GIF、パネルの背景画像、最大3ページ

## ご注意

- Zoyacdeck が他のプログラムの中でキーを押すことはありません。
- パネルはウィンドウモードやボーダーレス全画面のプログラムの上に表示されます。排他的な全画面モードの上には表示できません。
- 録画には無料ツールの ffmpeg が必要です。設定 > 録画 >「ffmpeg を入手」を押すと、公式の配布元からダウンロードします。
- 言語：Windows の言語に合わせて表示されます。設定 > 一般 > 言語 で変更できます。
- 終了するには：タスクバー右下のトレイアイコン（青緑の四角4つ）を右クリック → 終了
- 1日に1回新しいバージョンを確認し、ワンクリックでアップデートできます。
- 詳しい使い方は zip の中の `README.txt`（英語）をご覧ください。

## 更新履歴

### 1.0.3（2026-11-23）

- 動画マスを追加しました。PC の動画ファイルを1つ・複数・フォルダーごと入れると、マス（標準は横3マス × 縦2行）で繰り返し再生します。最初は音が出ず、ホイールでこのマスの音量だけが変わります。クリックで一時停止・再開、次・前の動画は右クリックメニューにあります。メディアバーやメディアキーには出てこず、パネルの濃さを下げても動画はくっきり表示されます。パネルを隠したり別のページに移ると一時停止します。
- タイマーの通知音の大きさをボタンごとに選べるようになりました（100%・75%・50%・25%・10%）。
- 行数を 1 行・2 行・3 行から選べるようになりました（設定 > パネル）。1 行では縦に長いボタンを「使えません」のマスとして表示し、削除はしません。3 行はボタンサイズの既定が最小で、カスタムで変更もできます（別に記憶します）。パネルが低いときはページの箱が 2 列にたたまれます。
- ボタン名を隠してアイコンだけ大きく表示できるようになりました（設定 > パネル > ボタン名）。既定では 3 行のときだけ隠し、マウスを乗せると名前が出ます。
- 名札シール（名前の後ろの丸い背景）をオン・オフできるようになりました（設定 > パネル）。自動シャットダウンとタイマーのマスにも同じシールが出るように直し、「音量 40」のようなお知らせはマスが狭いと文字を小さくして全部表示します。
- 動画マスを横5マス × 縦3行にもできるようになりました（3 行パネル用）。3 行パネルで新しく入れると最初から 5×3 です。
- タイマーの秒に 60 以上を入れると自動で分に直します（100 秒 → 1 分 40 秒）。

### 1.0.2（2026-11-23）

- モニターの明るさボタンを追加しました。ボタンの上でホイールを回すと5%ずつ、クリックすると30% → 60% → 100%の順に変わります。すべてのモニターをまとめて、または1台だけ選べます。外部モニターはモニターのメニューで DDC/CI をオンにする必要があります。
- カレンダーボタンを追加しました。クリックすると日付ごとにメモを書けるカレンダーが開きます。今日のメモがあるとボタンに赤い点が付きます。カレンダー上部の「背景」から画像を入れられます。

### 1.0.1（2026-11-22）

- パネルをドラッグして画面の端に近づけると、ぴったり吸着するようになりました。角では2辺に吸着し、タスクバーは避けます。さらにドラッグすると離れます。設定 > 一般 > 位置でオフにできます。
- ボタン編集画面をホイールでスクロールしているときに、ドロップダウン（サイズ・サウンドなど）や数値欄の上を通ると値が変わってしまう問題を修正しました。クリックしたときだけ変わります。
