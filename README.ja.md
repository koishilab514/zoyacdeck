# Zoyacdeck

Windows 用の小さなボタンパネルです。画面の好きな場所に置ける、ソフトウェア版のストリームデッキです。
プログラムやサイトを開く、音楽を操作する、マイクをミュートする、音声デバイスを切り替える、画面を録画する — どれもワンクリックでできます。

English · 한국어 · 日本語

## ダウンロード

**[最新リリース](https://github.com/koishilab514/zoyacdeck/releases/latest)** から `Zoyacdeck-バージョン.zip` をダウンロードして展開し、`Zoyacdeck.exe` を実行してください。インストールは不要です。

- Windows 10 / 11（64ビット）
- 初回起動時に「Windows によって PC が保護されました」と表示された場合は、**詳細情報 → 実行** を押してください。署名していない個人制作のソフトのため表示されます。

## できること

- **開く**：プログラム・フォルダー・インストール済みアプリ・Web サイト。デスクトップのショートカットやブラウザーのアドレスを空きマスにドラッグしても追加できます。
- **音楽**：前の曲・再生/一時停止・次の曲、曲名と音量が表示されるメディアバー
- **サウンド**：出力デバイスとプログラムごとの音量を変えるパネル、ワンクリックでのデバイス切り替え、特定のプログラムだけミュート、マイクのミュート
- **録画**：モニター全体・範囲・ウィンドウを録画。そのプログラムの音だけを録ることもできます。GPU でエンコードするので、ゲームが重くなりにくいです。
- **キャプチャ**：範囲・ウィンドウのスクリーンショットを PNG で保存し、クリップボードにもコピー
- **ウィジェット**：時計、日付、CPU / GPU / RAM の使用率、タイマー・ストップウォッチ、PC の自動シャットダウン予約
- **カスタマイズ**：5種類のカラーテーマ、ボタンに好きな画像や動く GIF、パネルの背景画像、最大3ページ

## ご注意

- Zoyacdeck が他のプログラムの中でキーを押すことはありません。
- パネルはウィンドウモードやボーダーレス全画面のプログラムの上に表示されます。排他的な全画面モードの上には表示できません。
- 録画には無料ツールの ffmpeg が必要です。設定 > 録画 >「ffmpeg を入手」を押すと、公式の配布元からダウンロードします。
- 言語：Windows の言語に合わせて表示されます。設定 > 一般 > 言語 で変更できます。
- 終了するには：タスクバー右下のトレイアイコン（青緑の四角4つ）を右クリック → 終了
- 1日に1回新しいバージョンを確認し、ワンクリックでアップデートできます。
- 詳しい使い方は zip の中の `README.txt`（英語）をご覧ください。
