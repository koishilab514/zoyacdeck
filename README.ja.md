# Zoyacdeck

Windows 用の小さなボタンパネルです。画面の好きな場所に置ける、ソフトウェア版のストリームデッキです。
プログラムやサイトを開く、音楽を操作する、マイクをミュートする、音声デバイスを切り替える、画面を録画する — どれもワンクリックでできます。

English · 한국어 · 日本語

## ダウンロード

**[最新リリース](https://github.com/koishilab514/zoyacdeck/releases/latest)** から `Zoyacdeck-バージョン.zip` をダウンロードして展開し、`Zoyacdeck.exe` を実行してください。インストールは不要です。

- Windows 10 / 11（64ビット）
- 初回起動時に「Windows によって PC が保護されました」と表示された場合は、**詳細情報 → 実行** を押してください。署名していない個人制作のソフトのため表示されます。
- ウイルス検査：例として **[v1.0.5 の VirusTotal の結果](https://www.virustotal.com/gui/file/b92630e11feff453e26f94568b91d87dab7f6b09152d261321c1b8b1f3cae65f)**。Microsoft Defender・カスペルスキー・ノートン・アバスト・ビットディフェンダーなど主要なウイルス対策ソフトでは検出されていません。一部のあまり知られていないエンジンが反応していますが、署名のない小さなソフトではよくあることです。ダウンロードしたバージョンを確かめたいときは、zip または exe を [virustotal.com](https://www.virustotal.com/) にアップロードしてください。

## できること

- **開く**：プログラム・フォルダー・インストール済みアプリ・Web サイト。デスクトップのショートカットやブラウザーのアドレスを空きマスにドラッグしても追加できます。
- **音楽**：前の曲・再生/一時停止・次の曲、曲名と音量が表示されるメディアバー
- **サウンド**：出力デバイスとプログラムごとの音量を変えるパネル、ワンクリックでのデバイス切り替え、特定のプログラムだけミュート、マイクのミュート
- **録画**：モニター全体・範囲・ウィンドウを録画。そのプログラムの音だけを録ることもできます。GPU でエンコードするので、ゲームが重くなりにくいです。
- **キャプチャ**：範囲・ウィンドウのスクリーンショットを PNG で保存し、クリップボードにもコピー
- **ショートカット**：使用中のウィンドウにキーボードショートカット（Ctrl+S、Ctrl+Z、F5 など）を送るボタン。編集・文書ソフトに便利です。
- **ウィジェット**：時計、日付、CPU / GPU / RAM の使用率、タイマー・ストップウォッチ、PC の自動シャットダウン予約、メモカレンダー、モニターの明るさ
- **動画**：PC の動画ファイルをマスで繰り返し再生
- **カスタマイズ**：5種類のカラーテーマ、ボタンに好きな画像や動く GIF、パネルの背景画像、最大3ページ

## ご注意

- Zoyacdeck が他のプログラムでキーを押すのは、追加したショートカットボタンをクリックしたときだけです。
- パネルはウィンドウモードやボーダーレス全画面のプログラムの上に表示されます。排他的な全画面モードの上には表示できません。
- 録画には無料ツールの ffmpeg が必要です。設定 > 録画 >「ffmpeg を入手」を押すと、公式の配布元からダウンロードします。
- 言語：Windows の言語に合わせて表示されます。設定 > 一般 > 言語 で変更できます。
- 終了するには：タスクバー右下のトレイアイコン（青緑の四角4つ）を右クリック → 終了
- 1日に1回新しいバージョンを確認し、ワンクリックでアップデートできます。
- 詳しい使い方は zip の中の `README-ja.txt`（日本語）をご覧ください。

## 更新履歴

### 1.0.8（2026-11-25）

- グラフィックチップが2つあるノートPC（例：NVIDIA + AMD・Intel の内蔵グラフィック）で「GPU エンコードが使えないため録画しません」と出て録画できなかった問題を修正しました。エンコードは引き続き GPU で行います。

### 1.0.7（2026-11-24）

- 付箋を追加しました。画面に貼っておけるメモです（編集画面 > その他 > 付箋）。
  - クリップのアイコンを押すと常に手前に表示されます。上の帯でホイールを回すと透明度が変わります。
  - 色は4色から選べます。位置・大きさ・文字は保存されます。
  - クリック透過をオンにすると、付箋の後ろのウィンドウをそのままクリックできます。Ctrl を押しながらマウスを乗せると一時的に解除されます。
  - 空の付箋は閉じると削除されます。
  - ボタンを押すたびに新しい付箋が出ます。
- PC が急に切れたり強制終了されたりしても、設定・カレンダーのメモ・付箋が壊れないようにしました。万一壊れてもバックアップから復元します。
- 新しいバージョンの確認を増やしました。起動時、1時間ごと、トレイメニューや設定画面を開いたときに確認します。

### 1.0.6（2026-11-24）

- 「常に手前」がオフでも、パネルをクリックすると他のウィンドウより手前に出るようにしました。使っていたウィンドウはアクティブのままです。他のウィンドウをクリックすると、パネルはそのウィンドウの後ろに戻ります。

### 1.0.5（2026-11-23）

- 最新の ffmpeg（9.1）で録画が始まらない問題を直しました。古い ffmpeg もそのまま使えます。
- 管理者の確認画面やロック画面が出ると、録画が音だけになったり止まったりする問題を直しました。画面が隠れている間は「一時中断」と出て、そのあと自動で続きを録画し、1つのファイルに保存します。
- 範囲指定の録画を音なしでできるようにしました（設定 > 録画 > 音 >「範囲指定の録画は音なしで」）。
- ページ・隠すボックスのツールチップが、離れたあともマウスの位置に遅れて出たり残ったりする問題を直しました。ボックスのすぐ上に出て、離れるとすぐ消えます。
- ボタン名を隠しているとき、タイマーと自動シャットダウンも待機中は名前を隠し、アイコンや時間を大きく表示します。動作中は終わる時刻がそのまま出ます。

### 1.0.4（2026-11-23）

- zip に日本語の使い方（README-ja.txt）を入れました。表示言語が日本語のときは、設定 > 情報 >「README を開く」で日本語版が開きます。
- ショートカットキーボタンを追加しました（ボタンを追加 > キーボード）。欄をクリックしてキーを押すか、コピー・元に戻す・保存・太字などよく使うものから選べます。ボタンを押すと使用中のウィンドウにそのショートカットを送るので、編集・文書ソフトに便利です。Win キーのショートカットも使えます（Win にチェック）。管理者として実行中のソフトには、Zoyacdeck も管理者として実行したときだけ届きます。
- アプリのアイコン（青緑の四角4つ）が右下に1ピクセルずれていたのを中央にそろえ、ふちをくっきりさせました。

### 1.0.3（2026-11-23）

- 動画マスを追加しました。PC の動画ファイルを1つ・複数・フォルダーごと入れると、マス（標準は横3マス × 縦2行）で繰り返し再生します。最初は音が出ず、ホイールでこのマスの音量だけが変わります。クリックで一時停止・再開、次・前の動画は右クリックメニューにあります。メディアバーやメディアキーには出てこず、パネルの濃さを下げても動画はくっきり表示されます。パネルを隠したり別のページに移ると一時停止します。
- タイマーの通知音の大きさをボタンごとに選べるようになりました（100%・75%・50%・25%・10%）。
- 行数を 1 行・2 行・3 行から選べるようになりました（設定 > パネル）。1 行では縦に長いボタンを「使えません」のマスとして表示し、削除はしません。3 行はボタンサイズの既定が最小で、カスタムで変更もできます（別に記憶します）。パネルが低いときは、右側のページ番号のボックスが 2 列に並びます。
- ボタン名を隠してアイコンだけ大きく表示できるようになりました（設定 > パネル > ボタン名）。既定では 3 行のときだけ隠し、マウスを乗せると名前が出ます。
- 名札シール（名前の後ろの丸い背景）をオン・オフできるようになりました（設定 > パネル）。自動シャットダウンとタイマーのマスにも同じシールが出るように直し、「音量 40」のようなお知らせはマスが狭いと文字を小さくして全部表示します。
- 動画マスを横5マス × 縦3行にもできるようになりました（3 行パネル用）。3 行パネルで新しく入れると最初から 5×3 です。
- タイマーの秒に 60 以上を入れると自動で分に直します（100 秒 → 1 分 40 秒）。

### 1.0.2（2026-11-23）

- モニターの明るさボタンを追加しました。ボタンの上でホイールを回すと5%ずつ、クリックすると30% → 60% → 100%の順に変わります。すべてのモニターをまとめて、または1台だけ選べます。外部モニターはモニターのメニューで DDC/CI をオンにする必要があります。
- カレンダーボタンを追加しました。クリックすると日付ごとにメモを書けるカレンダーが開きます。今日のメモがあるとボタンに赤い点が付きます。カレンダー上部の「背景」から画像を入れられます。
